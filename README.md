# Animal Detection System (ADS)

A real-time animal detection system designed to help reduce animal–vehicle collisions on roads, especially in rural areas.

## Project Overview

The Animal Detection System uses computer vision and deep learning to detect animals near roads and provide real-time warnings.

The AI component of the system was developed using **YOLOv5s**, which was selected for its balance between detection accuracy and real-time performance.

## My Role

I worked on the **AI and computer vision component** of the project, including:

* Preparing and working with the custom animal detection dataset.
* Training the YOLOv5s object detection model.
* Evaluating model performance.
* Improving detection performance through dataset preparation and retraining.
* Integrating the trained model with Raspberry Pi hardware for real-time detection.

## Technologies

* Python
* YOLOv5

* Deep Learning
* Object Detection

## Animal Classes

The model was trained to detect multiple animal classes, including:

* Cow
* Sheep
* Horse
* Dog
* Camel

## Results

The final model achieved approximately **83% mAP** on the custom dataset.

The model was designed with real-time detection in mind and tested for deployment on Raspberry Pi hardware.

## System Hardware

* Raspberry Pi 5
* Raspberry Pi NoIR Camera
* SIM7600 Cellular Module
* Speaker

## Project Goal

The main goal of the project is to provide an affordable real-time animal detection solution that can help reduce the risk of animal–vehicle collisions on roads.
